# content-streamer

## 目的

音楽・動画コンテンツのアップロード・管理・公開・再生までを行える、配信管理システムです。  
以下2つの業務領域を意識して設計しています：

- 音楽の著作権・配信管理システム
- コンテンツ（音楽・動画）の配信サイト構築業務

ポートフォリオ用として、短期間で構築可能な最小構成をベースにしています。

---

## スコープ

**対象範囲：**
- **管理者側（Admin）**
  - 音楽・動画コンテンツの登録（タイトル・説明・メディアファイル）
  - コンテンツの一覧表示、編集、削除（ActiveAdminを使用）
- **一般ユーザー側（Public）**
  - 公開されたコンテンツの一覧表示
  - 音楽・動画のブラウザ内再生（audio/videoタグを利用）

**対象外範囲：**
- ログイン機能
- コンテンツ分類（カテゴリ・タグ）、再生回数カウントなどの追加機能

## 機能要件（Requirements）

### 機能一覧（MVP）

| 区分     | 機能                           | 内容 |
|----------|--------------------------------|------|
| 管理者   | コンテンツ登録                 | タイトル・説明・音楽/動画ファイルをアップロード |
| 管理者   | コンテンツ一覧・編集・削除     | ActiveAdmin を利用した CRUD 操作 |
| 一般ユーザー | コンテンツ一覧表示             | 公開されたコンテンツを一覧表示 |
| 一般ユーザー | コンテンツ再生                 | `video_tag` / `audio_tag` によるブラウザ内再生 |

---

### 業務フロー

#### 管理者

1. `/admin` にアクセス（ログイン不要）
2. コンテンツ（音楽・動画）を新規登録（タイトル・説明・ファイル）
3. 登録済みコンテンツの一覧を管理（編集／削除）

#### 一般ユーザー

1. トップページ（`/`）にアクセス
2. 一覧からコンテンツを選択
3. ブラウザで音楽・動画を再生
